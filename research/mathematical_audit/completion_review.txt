Additional defects and repairs

1. Covariance ordering is substantive, not a cosmetic row choice. The DES FITS
file explicitly names spectra and starting indices in COVMAT's NAME_i/STRT_i
headers. The loader and block map now follow this declared ordering together.
They verify block starts and dimension coverage. Standard FITS repeated-string
formats such as 16A are recognized in SPECTRA tables. Missing spectra or VALUE
columns are errors; arbitrary numeric columns are not substituted for either
observed values or covariance. Synthetic FITS controls deliberately swap the
conventional xip/xim order and verify the observed-vector/covariance alignment.
The cached DES ordering remains xip, xim, gammat, wtheta; its 1000 values agree
exactly with the repaired block map.

2. The optional shear runner previously failed to recognize Z_MID, fell back
to toy source distributions despite a released nz_source table, and used
one-based FITS labels as zero-based Python tracer indices. It now selects the
fiducial nz_source table explicitly, reads only BIN columns, and retains their
integer labels as an explicit map to tracers. Lens distributions and source
realization tables cannot be selected accidentally. Missing source kernels
require an explicit allow_toy_nz choice before a toy fallback is allowed.
Angles are converted per row, unknown units/statistics fail, and SciPy's
trapezoid replaces NumPy's removed trapz entry point.

The released first source-bin tabulation contains a small signed calibration
tail. Its negative integrated mass relative to its net integral is about
4.10362e-4; the other three fiducial bins are nonnegative. The loader preserves
the released signed kernel and checks its positive net integral. It does not
silently project that table into a different probability distribution. A
successful optional smoke run records the signed mass, original bin labels,
kernel policy, multipole interval, and flat-sky finite-integral approximation.

The J0 calculation is tested against the analytic transform
integral_0^infinity ell*exp(-ell^2/2)*J0(ell*theta)/(2*pi) d ell

3. A single optimizer initialization at m=0 was too weak to support the sampled
constant-correction conclusion. Merely adding starts exposed a second defect:
L-BFGS could return success without moving from a starting point near a hard
BAO support boundary. The background comparison now uses bounded Powell
searches from three constant-family starts and four rewrite starts (m=0,1,3,6),
plus the exact embedding of each fitted constant family at m=0 whenever its
amplitude is admissible. An optimizer receipt retains each start, outcome,
score, and selected candidate. The profiled SN intercept is counted in that
receipt. Unsupported points have an actual infinite chi-square, rather than a
finite fake likelihood, and a selected failed fit is not published as success.

On the repaired inputs the constant-correction conclusion survives. The
SN-only best constant fit is approximately (om,A)=(.2920765,.5520879) with
chi2=1639.09649487. The SN+BAO best fit is approximately
(.3006449,.5473573) with chi2=1640.41118037. The exact nested rewrite at m=0
attains the same score. The added parameter therefore costs Delta AIC=2.
This verifies the best candidate among the declared searches; it is not an
interval-certified global optimization theorem over a continuum.

4. Checking H^2 only at integration samples can miss a negative interior
interval. Both background distance families now check analytic candidates on
the entire integration interval. For LCDM, with u=1+z,
f(u)=om*u^3+ok*u^2+ol has derivative u*(3*om*u+2*ok), so endpoints and its
possible stationary point suffice.

For the declared nonnegative public rewrite coefficients om,A,m,
f(u)=om*u^3+ok*u^2+A*u^(-m) has derivative u*D(u), where
D(u)=3*om*u+2*ok-m*A*u^(-m-2). Here
D'(u)=3*om+m*(m+2)*A*u^(-m-3)>=0. Consequently endpoints and the unique
possible interior zero of D exhaust the minimum candidates. A bracketed root
solve evaluates that candidate before integration. A regression uses
(om,A,m)=(.05,2,0): both z=0 and z=25 are allowed, but the interior minimum
at z=13 is negative. A two-point integration grid previously accepted it.
The repaired code rejects it. These are floating evaluations of an analytic
criterion, not interval certificates arbitrarily close to degeneracy.

For flat wCDM, f(u)=u^3*(om+(1-om)*u^(3*w)). The parenthesized factor is
monotone, so endpoint positivity excludes an interior zero. Its distance path
now performs this check explicitly. The public rewrite also has an exact
constant-w subfamily when A=1-om: w=-1-m/3, wa=0. This follows by comparing
the fluid exponent 3*(1+w)=-m and is checked for m=0,1,3,6. The previous
curved-source to flat-CPL fit remains an H-only approximation; no growth
prediction is inferred from that scalar match.
